## Project Overview
Deck of Cards is an interactive web application
developed using React.js, JavaScript, and CSS.

The application allows users to interact with
a standard 52-card deck through different
card management features.

## Features
- Draw random cards from a 52-card deck
- Deal 5 or 7 random cards
- Select and highlight individual cards
- Swap the positions of two cards
- Toss selected cards
- Generate random wildcard cards
- Shuffle cards using the Regroup button
- Reset the deck to its original state

## How to Run the Project

1. Clone the repository:

   git clone https://github.com/Az330/a3_deck_of_cards.git

2. Navigate into the project:

   cd a3_deck_of_cards

3. Install dependencies:

   npm install

4. Start the application:

   npm start

5. Open http://localhost:3000
